# ADR-0016: 한국어 기본과 영구 한국어·영어 전환

Status: accepted by user direction. Date: 2026-09-18. Extends [ADR-0015](0015-anonymous-korean-repository-reports.md).

## 배경

공개 저장소 리포트는 한국어 데모로 출시했지만, 같은 공개 링크를 영어 사용자가 열 수 있다. 클라이언트가 뜬 뒤에만 언어를 바꾸면 첫 HTML의 `lang`, 제목, 설명이 화면과 달라지고 새로고침 때 한국어가 잠깐 보일 수 있다. 한편 `repository-report-v1`은 서버와 브라우저가 엄격하게 검증하는 결정론적 계약이며, 고정 한국어 설명도 그 검증 대상이다. 화면 번역 때문에 저장 이력이나 API 계약을 언어별로 분기하면 같은 리포트의 재현성이 깨진다.

## 결정

한국어를 기본 언어로 유지하고 공통 헤더에 한국어·영어 전환을 둔다. 선택은 검증된 `myaiscore_locale=ko|en` 쿠키에 1년 동안 보존한다. 서버 레이아웃은 첫 응답에서 쿠키를 읽어 `<html lang>`, 제목, 설명을 같은 언어로 렌더링한다. 알 수 없는 값은 한국어로 처리한다. 클라이언트 전환은 화면과 `lang`을 즉시 갱신하고 서버 컴포넌트를 새로 고친다.

UI 문구는 의존성 없는 타입 고정 카탈로그에서 관리한다. 공개 저장소 API와 브라우저 이력은 계속 정본 `repository-report-v1`을 저장하며 번역문을 쓰지 않는다. 영어 표현은 축, 스타일, 근거 카드 같은 안정된 의미 ID와 coverage 상태에서 렌더링 시 계산한다. API 실패는 서버의 자유 문구 대신 안정된 `error.code`로 번역하고, 알 수 없는 코드는 일반 오류를 보여준다.

현재 기본 경로 `/`, `/evaluate`, `/profile`, `/insights`는 두 언어를 완성된 화면으로 제공한다. 과거 평가·공유·walkthrough 본문은 원래 영어 기록을 보존하되 공통 탐색과 footer는 선택 언어를 사용하고 영어 본문 영역에 `lang="en"`을 표시한다.

## 결과와 대안

- URL prefix나 query 대신 쿠키를 선택했다. 현재 링크 구조와 브라우저 로컬 이력을 그대로 유지하면서 첫 응답 언어를 결정할 수 있다. 언어별 검색 URL이 필요해지면 별도 라우팅 결정을 한다.
- `localStorage`만 사용하지 않는다. 서버가 첫 HTML 언어를 알 수 없어 hydration 전후 의미가 달라지기 때문이다.
- 번역 라이브러리를 추가하지 않는다. 지원 언어와 화면 수가 작고 함수형 복수 표현만 필요하다. 언어 수, 날짜·통화 형식, 번역 파일 운영이 커지면 전용 도구를 다시 검토한다.
- 쿠키는 언어 설정만 담으며 인증이나 개인 리포트 데이터가 아니다. 리포트 저장 범위와 개인정보 경계는 ADR-0015를 그대로 따른다.
