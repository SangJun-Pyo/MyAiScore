# ADR-0005 — 결과 차이와 행동 향상을 분리한다

- 상태: Accepted
- 기록일: 2026-09-14 (Phase 4 사후 기록)
- 결정 주체: Astra, 기존 비교 원칙의 구현
- 기준: PR #6 / `db0edd7`; 대체 관계: 없음

## 배경

같은 프로젝트라도 모델·기준·자료 범위가 달라지면 점수가 달라질 수 있다. 과거 기록을 추가한 것만으로 현재 행동이나 개인 역량이 향상됐다고 판단할 수 없다.

## 결정

같은 저장소의 실제 완료 평가에 대해 모델/제공자 식별, 평가·프롬프트 버전, 근거 종류/수준, 수집 범위와 양쪽 총점 발급을 확인한 경우만 숫자 차이를 제공한다. 그 밖에는 scoreDelta=null과 사유를 보여준다. 축별 관찰 상태, 근거 변경, commit 변경은 별도로 제공한다. 현재 구현의 behaviorChange는 항상 not_established다. 호출 API는 두 결과 모두의 소유 권한을 확인한다.

## 대안

- 총점 두 개를 언제나 빼기: 서로 다른 평가 조건을 같은 척도로 오해하게 한다.
- 점수/레벨 상승을 성장으로 표시: 기록 추가와 새 행동을 구분하지 못한다.
- 비교 기능 전체 보류: 숫자 비교가 불가능해도 바뀐 근거와 미확인 사유를 보여주는 효용은 있어 제한적으로 구현했다.

## 결과와 재검토 조건

비교 가능한 결과가 적어질 수 있다. 현재 범위 검사는 수집 파일 수뿐 아니라 경로도 확인하지만 교란 요인을 모두 통제한 인과 검증은 아니다. 행동 변화를 주장하려면 실제 전후 행동과 결과의 연결 기준을 별도 정의·검증해야 한다.
