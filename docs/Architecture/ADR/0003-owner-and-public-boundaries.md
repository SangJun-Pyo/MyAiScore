# ADR-0003 — 소유 토큰과 공개 결과 경계를 분리한다

- 상태: Accepted
- 기록일: 2026-09-14 (Phase 4 사후 기록)
- 결정 주체: Astra, 로그인 없는 MVP의 비공개 자료 보호 구현
- 기준: PR #6 / `db0edd7`; 대체 관계: 없음

## 배경

로그인을 필수로 두지 않으면서 사례·발췌·답변을 비공개로 보관해야 한다. 소유 결과를 그대로 공유하면 모델이 원문을 재인용하거나 내부 context가 직렬화될 수 있다.

## 결정

서버가 임의 소유 토큰을 발급하고 저장에는 hash만 남긴다. 브라우저는 탭의 sessionStorage에 토큰을 보관하고 비공개 조회/변경에 제시한다. 공개는 사용자가 별도로 선택한 공유 ID로 제공하며 철회·삭제할 수 있다. 공개 DTO에는 원문/context 및 모델 자유 서술을 넣지 않고 제한된 점수·축 요약과 일반 안내를 사용한다. 평가 완료 시 임시 prepared 입력을 제거한다.

## 대안

- 필수 계정 로그인: 복구/다중 기기 이용에는 유리하나 MVP의 로그인 없는 범위에서 보류했다.
- 평가 ID만 알면 비공개 조회 가능: 식별자와 권한을 혼동하므로 배제했다.
- 원문을 마스킹해 소유 결과 그대로 공개: 휴리스틱 마스킹 실패나 모델 재인용 경로를 완전히 막지 못하므로 공개 필드 자체를 제한했다.

## 결과와 재검토 조건

공개 결과의 설명은 소유 화면보다 제한된다. 탭의 토큰을 잃으면 복구할 수 없고 토큰 유출은 소유 권한 유출이다. 계정 복구·다중 기기 요구가 생기면 인증 모델을 재검토한다. 이 구조가 전체 PII 제거 또는 XSS 방어의 완전성을 보증하지 않는다.
