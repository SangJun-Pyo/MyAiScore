# ADR-0015: 로그인 없는 한국어 저장소 리포트

Status: accepted by user direction. Date: 2026-09-18. [Issue #28](https://github.com/SangJun-Pyo/MyAiScore/issues/28).

## 배경

배포된 CLI 중심 흐름은 원문을 로컬에 두는 장점이 있지만, 처음 방문한 사용자가 저장소 설치와 터미널 명령을 이해해야 한다. 공모전 제출은 로그인 없이 바로 작동하는 기능을 요구하고 심사 시간이 짧다. 사용자는 공개 GitHub 소스 접근과 한국어 데모를 제안했고, CLI 부담을 낮추는 방향을 명시적으로 채택했다.

GitHub 공개 저장소는 인증 없이 읽을 수 있지만 비인증 API 허용량은 서버 IP당 시간당 60요청이다. 현재 bounded 수집은 저장소 하나에 수십 요청을 사용할 수 있으므로 배포 서버는 선택적으로 읽기용 `GITHUB_TOKEN`을 사용한다. 토큰은 Railway 서버 환경에만 두고 응답·로그·브라우저에 노출하지 않는다. 사용자의 GitHub 로그인과는 별개다.

## 결정

기본 제품은 한국어 단일 화면에서 공개 GitHub 저장소 URL 하나를 받아, 서버가 고정된 GitHub API 주소에서 공개 커밋을 제한적으로 수집하고 결정론적 저장소 리포트를 반환한다. 계정·OAuth·Supabase·서비스 LLM·추가 질문은 필요하지 않다. 분석 요청과 결과를 서버 DB에 보존하지 않으며, 사용자가 선택한 결과만 해당 브라우저 저장소에 저장한다.

리포트는 저장소에서 관찰 가능한 네 종류의 신호를 각각 최대 25점으로 요약한다: AI 맥락, 검증 기반, 결정 추적, 자동화 기반. 실제 세부 규칙과 버전은 [REPOSITORY_REPORT](../../Assessment/REPOSITORY_REPORT.md)가 정본이다. 근거 카드에는 수집된 저장소 경로와 고정 설명만 넣는다. 저장소가 작성자의 실제 대화·판단·기여자를 증명하지 않으므로 결과를 개인 AI 실력, 생산성, 채용 등급, 코드 정답 또는 백분위로 표현하지 않는다. 부분 수집은 coverage에 드러낸다.

Claude Code 세션 CLI와 숫자 요약 계약은 삭제하지 않고 선택적인 상세 분석으로 유지한다. CLI가 기본 진입점이라는 ADR-0014의 제품 우선순위만 이 결정이 대체한다. 과거 다섯 축 평가·소유권 API와 walkthrough도 호환 목적으로 유지하되 기본 탐색에서 분리한다.

제품 UI는 한국어를 기본으로 한다. 이는 영어 전용을 정한 ADR-0010과 ADR-0014의 언어 범위를 대체한다. 기존 차콜·코럴 시각 체계와 반응형·접근성 규칙은 유지한다.

## 대안과 결과

- GitHub OAuth를 기본으로 두면 공개 저장소에도 로그인 장벽이 생기므로 채택하지 않는다. 비공개 저장소가 우선순위가 되면 저장소별 최소 권한과 단기 토큰을 제공하는 GitHub App을 별도 설계한다.
- 저장소 소스만으로 실제 AI 협업 과정을 단정하지 않는다. 로컬 세션 파일 브라우저 분석은 원문을 서버에 보내지 않는 선택 기능으로 후속 검토한다.
- Cloudflare 정적 export로 바꾸지 않고 현재 Railway Next.js 서버에서 bounded 수집을 수행한다. 배포 환경의 `GITHUB_TOKEN`은 허용량을 높이기 위한 서버 비밀이며 private 저장소 접근을 제품 기능으로 활성화하지 않는다.
- 로그인·서버 이력·리더보드는 제출 뒤 별도 결정이다. 현재 결과는 브라우저별이며 기기 간 동기화를 약속하지 않는다.
