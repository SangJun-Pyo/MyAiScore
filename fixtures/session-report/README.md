# Synthetic Claude Code session report input

`basic.jsonl` is authored test data, not a real person's transcript. It includes repeated streaming IDs, tool-result wrappers, missing result status, a failed check, a quoted command, fake sensitive values and an injection-shaped string. The collector produces counts and fixed copy only. Its `/synthetic/myaiscore` cwd is intentionally not a real project; CLI tests replace it with a temporary project path.
